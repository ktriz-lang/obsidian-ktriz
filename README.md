# obsidian-ktriz

Obsidian Community Plugin that renders ` ```ktriz ` code blocks — `.ktriz.kts`
scripts using [kTRIZ](https://ktriz.dev)'s `functionModel { }`/`suField { }`
DSL — as inline SVG in Obsidian notes.

Sibling project to [obsidian-kuml](https://github.com/kuml-dev/obsidian-kuml),
which does the same for [kUML](https://kuml.dev) diagrams. Not yet
implemented — this is the repository scaffold; the actual plugin lands in a
follow-up wave.
